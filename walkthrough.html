For the CIRC teaching team · Updated October 31, 2026

Start with Open CIRC HQ and keep this guide beside the app. Take a five-minute preview first. Allow about 30-45 minutes for the full tour at your own pace; real schedule and account setup can wait until you are ready.

CIRC HQ brings the teaching day, lesson directions, clocks and room routines together. Its announcement studio helps prepare the show. You decide what gets saved, what students see and when the class or broadcast begins.

Start with the preview. Then follow the chapter for the tool you need. Account setup is optional. If your version does not show one of the newer buttons described here, follow that section's availability note. This guide does not mean either teacher's real schedule, account or room is already configured.

1. Click the link and preview a lesson

  1. Open CIRC HQ. A fresh browser offers Student side and Teacher side.
  2. Choose Open teacher side, then Preview a lesson. The current lesson opens with a Preview only label. At this update it is Logo to jingle, Playbook A meeting 3.
  3. Read the goal and first step. Expand More teacher help or More context when you need them.
  4. Practice Start class, Pause, Resume and Next Step. The preview does not save a real class or advance its progress. Reloading ends it.
  5. Choose Student directions to see the projected step. Teacher controls returns to the same runner. Exit student view returns to Today.
  6. Choose Back to Today, then Choose a lesson to explore both annual playbooks.

If this browser already has a real schedule, keep it. Use the preview without changing that timetable or clearing its saved work.

3. Build your real schedule

Click: Set up my schedule, or Schedule. Each teacher uses their actual timetable and their own teaching browser/profile.

  1. Enter Teacher name. Each teacher enters their own display name.
  2. Enter First school day, Last school day, and Cycle day on the first school day from the confirmed calendar. Do not use today's date as an invented first-day anchor.
  3. Open Day 1. Add actual blocks with Add class, Add prep, Add lunch, Add support and Add duty.
  4. Review each row's Kind of time, Name, Starts and Ends. The app sorts the blocks into time order.
  5. Repeat for Day 2 through Day 5. Copy this day to and Copy to Day… help when days really match; check the destination and all copied times. Remove removes the selected draft row.
  6. Read Check these schedule details and correct invalid or overlapping times. Choose Save schedule. Cancel leaves the editor without keeping draft edits.
  7. Return to Today and compare its cycle day, current/next block and duties with your timetable. If a multi-teacher plan shows Editing schedule for, verify the teacher before editing.

Saving changes local data. It does not automatically sign you in or upload your timetable. Advanced backup is for recovery; ordinary schedule setup needs no imported file.

4. Use Today and choose this class's lesson

Click: Today. Your saved timetable controls the class context. Read the date, cycle day and teacher identity first.

  1. On a new device, choose Set up my schedule or Load a private schedule file. Both playbooks work while you are still setting up.
  2. With a timetable saved, check the next obligation and the class card. Choose the correct grade path and actual meeting for that class. Meetings count class visits, not calendar weeks.
  3. Read the goal, first step and pacing strip. Use the lesson controls to run the class; opening a lesson does not mark it finished.
  4. Use Handouts and guides for the matching lesson PDF or Word response sheet. My week opens the five-day view.
  5. More tools holds weather, the wider timeline and earlier project tools. A missing forecast is not a forecast of good weather.
  6. Choose a lesson opens Playbooks. If the current class and its lesson have both been reviewed for classroom display, that shortcut becomes Open Board.

To project an ordinary playbook lesson, start its runner and choose Student directions. The reviewed Board remains a separate overview; it never substitutes private class or lesson text.

5. Choose a playbook and the right handout

Click: Playbooks. Playbook A is the 2026-27 route; Playbook B is the 2027-28 route. Pick the meeting and, where offered, Grade 5 or Grade 6. The two routes share some lessons, so there are 74 unique lesson handouts rather than 74 visits for each class.

  1. Read the goal, before-class preparation, materials and safety. The teacher plan includes a matching student direction at each timed step.
  2. Choose Start this lesson for the runner, Open student page for independent reading, or Lesson PDF to print only that lesson.
  3. Open Handouts and guides. Search a lesson name and filter by grade, playbook or format.
  4. Student PDF gives the directions, finish check and fallback. Response sheet downloads an editable Word file. Open on screen opens the same lesson online.
  5. For a Teams assignment, attach the response sheet and verify the tenant's option for each student to edit their own copy. The download does not create or publish an assignment.

The October 31 annual teacher guide and bookmarked screen cards match the current lessons, including Logo to jingle. The large screen-card deck is for projection, one step at a time. The Classroom Toolkit, Ethernet lab and build-station packets are also linked from the guide section.

More keeps the earlier 36-experience library and replica lessons available. They are extra teacher choices, not a second required annual route. Choosing a different lesson never proves that a class has completed it.

6. Run a class one step at a time

Click: Playbooks → Start this lesson, or open the lesson runner from the current class card on Today.

  1. Read the first step and arrange materials. The runner opens Ready, with stationary clocks.
  2. Choose Start class when students are ready. The step and class clocks begin.
  3. During a scheduled class, the class clock uses actual remaining time. Starting late does not extend the school timetable. Without a current class, the reviewed plan uses 35 minutes.
  4. Project Student directions. It follows the same active step and timers. Teacher controls returns to the current runner; Exit student view returns to Today.
  5. Move steps yourself. Expiry waits for you. Choose Finish Lesson at the final step, then inspect cleanup and work before advancing any broader progress.
Control Effect
Pause / Resume Hold the active runner, then continue.
+1 min Add a minute to the current step, without extending the school timetable.
Previous / Next Step Move manually through the plan.
Pause for a question Hold the build step while the real class clock continues during discussion.
Add 2 minutes / Return to build Extend the detour or resume the build.
Safe Landing Move from the detour to the first cleanup step.
More teacher help / More context Immediate teaching help or the broader plan.
Start this lesson for a new class Confirm a fresh run of this lesson at step 1.

In preview mode, reloading resets the timer. With a saved teacher context, the runner belongs to the device that starts it. Another signed-in device is not a remote synchronized clock. Reopening the same special lesson preserves its step/timers, including completion; use the explicit new-class control for the next group.

When students open the link on their own device

Open Student side. Tap Grade 5 or Grade 6 for the suggested lesson, or enter the playbook and meeting your teacher wrote on the board. Use All lessons to search by name, grade, playbook or paper-only path.

The lesson puts the goal, done-when check and grade target first, followed by materials, safety, numbered steps, turn-in directions and an optional challenge. Student PDF opens the matching printable directions. This page does not collect work or run a student's private timer.

8. Prepare the announcement script

For the prepared school script, open ECTV scripts and check the date. The optional studio below keeps a separate local working draft; it does not update the published script automatically.

Click: Playbooks → Open announcement studio. The heading is Run today's broadcast, with TEACHER BACKSTAGE / KEEP OFF PROJECTOR. This is The Morning Ehrman Show / Grade 6 Morning Announcements preparation area.

  1. Set Announcement date and review Target minutes. ECTV remains 8:50 a.m. crew arrival after homeroom, 8:55 a.m. broadcast, with a roughly three-minute complete script.
  2. Choose Use ECMS outline. If text exists, read the replacement confirmation.
  3. Prepared date buttons are historical examples. Use one only when it matches the actual broadcast date, then replace old notices with approved current wording.
  4. Fill Opening, Moment of silence, Pledge and required school notices, Special events, optional Optional reminder or weather, and Closing, using current approved notices/lunch and approved first names.
  5. Resolve every [[placeholder]]. Unresolved markers block review and Go live.
  6. Complete Prepare, rehearse the full script, enter Rehearsal time in seconds, and complete Rehearse. Teacher review then becomes available. The teacher reviews the final words before approval.
  7. Choose Save local draft. This saves the working copy and a separate copy for that date in this browser.

The outline preserves introductions, at least 20 seconds of silence, a separate 5-second handoff before the full Pledge, sit cue, required notices, lunch, optional reminder and closing. The handoff pause does not replace the silence.

9. Save dates, check the crew and display the show

On Day 4, prepare next week's actual dates individually. Choose a date, edit and Save local draft for each day. Saved broadcast dates → Load opens an archived date. Changing the date field edits the current script; it does not load another date. Save again after edits. Start a blank draft clears the working draft while retaining saved dates.

For each announcer, the teacher records Student says they checked in with their homeroom teacher before coming to CIRC, Arrived in CIRC, and Ready to read the rehearsed script. These are local teacher checks, not attendance records or messages.

  • Adjust recommended crew times: 8:50 arrival, 8:52 backup decision, 8:54 final check, 8:55 broadcast. Time alone does not replace a student.
  • Delay or backup options: arrange a rehearsed backup or explicit teacher coverage. A backup needs fresh checks.
  • Crew assignments changed: reset checks: clears role checks while preserving separate script review.
  • A loaded date may restore old checks; review the actual crew. Date/introduction changes clear checks; wording changes require review again.

Go live requires script approval and confirmed/covered roles. It opens a script display. It does not start the school's transmitter, camera, microphone, Teams meeting, HDMI output or ECTV player. Follow the studio equipment procedure. Exit broadcast view returns backstage. Finish the checklist and reset equipment after the show.

Where the other tools fit: a school-approved team or resource folder holds messages, crew forms, printable scripts and media. Those files and forms do not import automatically into CIRC HQ. Use the teacher's approved location and equipment instructions.

10. Private crew sign-up and student production

Open private crew sign-up is teacher-controlled. Choose class, first name, date, job and primary/backup, then Save this sign-up. Pair each job with a different backup. The standard crew has two announcers, four reporters and two camera operators; up to two producers are optional. Review the selected date and use Remove only for an intended removal.

This browser-local form is separate from the school-only Microsoft Form. It does not accept remote student entries, fill the script or approve broadcasting. Saved dates and paper fallback explains a private paper alternative. Keep names/backstage off the projector.

Open student work area shows three desks, numbered stages, three short actions, a Bring back result and Need the full directions?. Choose stage buttons or Next step. Stop projecting before Teacher: exit student work area.

Desk Stages Outcome
Film Plan → Edit → Review A pitch and three shots, then a reviewed 15-45-second iMovie story; keep the editable project.
Reporting Pitch → Report → Review A pitch/three questions, then a checked 3-5-sentence story with sources.
Weather Check → Write → Review A dated forecast note, then a checked 15-20-second weather line.

Film uses a wide scene, evidence close-up and clear ending; paper storyboards work without a camera. Reporting offers CIRC build updates, kindness, school events, how-to stories and outdoor questions. Weather links to NWS forecast, hourly forecast and radar; check location/date/update time. Radar describes observations, not a promise of future weather.

Recording/editing/saving happen in the chosen media or paper workflow. The app does not collect assignments or publish stories. Current full directions mention the September 9-10 launch window; the teacher chooses new work afterward. The teacher's themes start September 14: Maker Monday, Tell-Me Tuesday, Wacky Wednesday, Think-It-Through Thursday, Fun Friday. They are not an automatic app feed. September 11 remains respectful remembrance.

13. Optional sign-in, sign-up and private sync

Click: Sign in to sync, or Settings → Open sync setup. Each teacher uses their own account for their private schedule; this does not enroll students.

Choose an available sign-in option. Continue with Google uses the selected Google account. Explore a temporary demo is a memory-only tour, not registration. Setup then confirms the teacher, reviews the schedule, turns on private sync and verifies the result before Ready for Today.

  1. After sign-in, read Confirm your account. Choose Use this account only for your identity; Use a different account changes it.
  2. Choose Build my schedule, or review Saved schedule found in CIRC Cloud before Use this schedule / Use saved cloud schedule.
  3. Read Private to the signed-in teacher and Stays on this device. Turn on private sync is the deliberate upload/verification action; opening setup is not proof of sync.
  4. Wait for Verify CIRC Cloud. At CIRC HQ is ready, check teacher, cycle day, plan, last verified sync and backup, then Open Today.
  5. On another trusted device, use the same teacher account and verify the correct timetable before teaching. Review a wrong identity, conflicting plan or incomplete sync before any overwrite.

If Sign up with any email is available: enter your school or other email and choose a separate CIRC HQ password, then select Create account with email. Returning users choose I already have a CIRC HQ account, then Sign in with email. Forgot password is the recovery path. If the option is unavailable or reports that email accounts are not enabled, continue locally and ask the project owner to activate this route.

Setup help holds account/recovery choices. Local teaching remains available after sign-in failure. No real Google authorization, email registration or cross-device sync was completed for this guide.

14. Optional room for the teaching team

After both private setups are correct, open Setup help → Optional room. One teacher chooses Create CIRC room; the other enters the one-time invitation code and chooses Join CIRC room. Share the code directly with the intended teacher and verify membership. Sending an invitation is not a completed join.

A room coordinates selected room-artifact/progress records. It does not merge private timetables, create student accounts or synchronize every local feature.

15. Settings, calendar exceptions and recovery

Settings → Open Schedule returns to the timetable; Open sync setup returns to account setup.

For a confirmed exception, use the date/action: Add closure, Set makeup-day status, Set cycle-day override or Add special event. Makeup choices are Pending, Instructional and Closed. Review the staged result, choose Save calendar change, then verify Today. Staging is not saving; a configured schedule is required.

Weather resource identifies Open-Meteo for bus duty; the NWS student links serve a separate reporting task. When available, Refresh weather requests a new forecast, Retry weather retries an unavailable or stale one, and Updating weather... marks a request in progress. A last reading labeled Updated earlier is not current verification.

Open Advanced backup and restore → Export backup before major changes. To restore, select the correct file, inspect its preview and confirm only the intended restore. Ordinary setup needs no backup file. Do not clear browser storage to hide a recovery warning.

Problem Next action
Schedule absent in another browser Return to its original browser or use that teacher's verified private sync.
Sign-in fails Continue locally and use Setup help. Email sign-up is deployed; an account or provider error needs its own check.
Wrong teacher or cloud conflict Preserve a backup and review identity/recovery before replacement.
Announcements missing elsewhere Check the original studio browser; scripts do not sync.
Timer reaches zero Choose Next Step when ready; it waits.
Go live unavailable Read Finish these before teacher review; resolve markers, rehearsal, approval and crew checks.
Saved-state recovery screen Use explicit backup preview/restore; preserve existing storage.
School Moodle database error Use Teams/downloaded files; Moodle, CIRC HQ and Teams are separate.

Different site addresses, local previews and direct file views have separate storage. Use the intended public site and chosen browser for real work. Clearing site data or changing profiles can remove access to local work.

16. Your first real day

  1. Before students: Today → confirm teacher/cycle/blocks → Room → Morning setup.
  2. ECTV: Load the actual date on the studio browser. Check office changes, crew, rehearsal and equipment. Arrival after homeroom by 8:50; broadcast at 8:55.
  3. Before class: Open the plan, check materials/first step, then Start class. Project Student directions.
  4. During class: Move steps yourself. Use Question Detour/Safe Landing as needed; finish cleanup and exit check.
  5. Between classes: Reset a special lesson for the new class and record only the handoff that happened.
  6. Planning: Browse the next experience. On Day 4, prepare/save every next-week announcement date.
  7. Leaving: Leave one clear next action, reset the first surface and retain the known working browser/backup.

You can stop after the preview on your first visit. The rest stays ready for the day you need each tool; account setup and the whole calendar need not happen in one sitting.
