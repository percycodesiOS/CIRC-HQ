Reporters and computer

How we edit stories in iMovie

Same workflow as the student PDF in Studio Media. Keep it short. Keep it true. No watermarks.

Back to ECTV home Open Studio Media Resources

01 / Prep

Before iMovie

1

Topic approved

Get the topic approved before you film.

2

Three shots

Film wide, close-up evidence, and a clear ending.

3

Sound test

Record a 5-second sound test and listen.

Don't forget: check in with your homeroom teacher first, always.

02 / Magic Movie

Build the project

1

Start New Project

Open iMovie. Choose Start New Project, then Magic Movie.

2

Select clips

Select your clips and photos for the story.

3

Create Magic Movie

Tap Create Magic Movie. Aim for 30 to 45 seconds unless Mr. Macek says otherwise.

Trim waiting and mistakes if needed. Keep one clear title with the main fact. Check facts. Remove anything private or unapproved.

Default student path: Start New Project, Magic Movie, select media, Create Magic Movie.

03 / Finish

Export, upload, share

Do these steps before review.

1

Export

Export the finished Magic Movie from iMovie. Keep the editable project.

2

Upload to school OneDrive

Upload the export to your school OneDrive folder for ECTV.

3

Share with Mr. Macek

Share that OneDrive file with Mr. Macek. Do not publish it yourself.

04 / Review

Review before airing

Review comes after export, upload, and share. It comes before the story airs.

1

Partner check

Ask a partner what the story is about. Fix anything confusing.

2

Teacher review

Mr. Macek reviews the shared OneDrive file before airing.

3

Ready for show

Only then can the story be used on ECTV.
